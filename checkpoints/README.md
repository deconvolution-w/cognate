# Model checkpoint

Place the released COGNATE weights in this directory as `checkpoint.pth`.
The weight file is intentionally excluded from Git because it is approximately
2.8 GiB and exceeds the file limit of standard Git hosting. Distribute it as a
release asset or through the archive associated with the manuscript.

Expected file:

```text
checkpoint.pth
size: 2942394441 bytes
sha256: c5fa99446ffa1f74ff8147d2c322f4129364b971e69d629d3ca1dd9ec4b892cc
```
